# Clinic Management System

Application web de gestion de rendez-vous médicaux développée avec Symfony 7 et PHP 8.  
Le projet permet de gérer les patients, les médecins, les rendez-vous et les dossiers médicaux.

## Fonctionnalités
- Gestion des patients  
- Gestion des médecins  
- Gestion des rendez-vous  
- Gestion des dossiers médicaux  
- Authentification et rôles (admin, médecin, secrétaire, patient)

## Technologies utilisées
- Symfony 7  
- PHP 8  
- MySQL  
- Bootstrap 5  
- Twig
